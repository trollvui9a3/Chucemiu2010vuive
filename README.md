# Website bất ngờ dành cho crush 💗

## Chạy thử
1. Giải nén file ZIP.
2. Mở thư mục `crush_surprise_web`.
3. Mở `index.html` bằng Chrome/Firefox để xem thử.

## Thêm ảnh của bạn
- Chép ảnh vào thư mục `images`.
- Đặt tên lần lượt `1.png`, `2.png`, `3.png`.
- Nếu dùng JPG, hãy đổi phần tên trong `index.html` từ `.png` thành `.jpg`.
- Muốn thêm ảnh nữa: sao chép một khối `<figure class="photo-card ...">...</figure>` trong `index.html`, đổi tên ảnh và caption. Ba ảnh đầu có hiệu ứng nổi/3D nhẹ.

## Cá nhân hóa lời nhắn
Mở `index.html` bằng trình soạn thảo văn bản:
- Sửa tiêu đề “Cậu có thể mở món quà này không?”
- Sửa nội dung bên trong `<p class="letter" id="letter">...</p>`.
- Sửa câu hỏi cuối trang nếu muốn.
Giữ nguyên các dấu ngoặc `< >` và tên class/id để tránh làm hỏng trang.

## Đưa lên mạng miễn phí bằng Netlify Drop (dễ nhất)
1. Trên máy tính, mở `https://app.netlify.com/drop`.
2. Đăng nhập/đăng ký nếu trang yêu cầu.
3. Kéo **cả thư mục `crush_surprise_web`** vào vùng tải lên. Nếu Netlify không nhận thư mục, hãy nén thư mục thành ZIP rồi làm theo hướng dẫn trên trang; hoặc dùng GitHub Pages.
4. Chờ trang tạo link công khai. Mở link đó trên điện thoại để kiểm tra, rồi gửi link cho người ấy.
5. Giữ thư mục gốc để sau này sửa nội dung và tải bản mới lên.

## Lưu ý
- Website không có nhạc, không cần cài thư viện JavaScript.
- Google Fonts chỉ dùng để tải font; nếu mất mạng thì trang vẫn hiển thị bằng font dự phòng.
- Chỉ dùng ảnh mà bạn có quyền chia sẻ. Nếu ảnh riêng tư, hãy cân nhắc trước khi đưa lên một website công khai.
